## What I'm building

**[home-infra](https://github.com/preston-bernstein/home-infra)** — Docker Compose stacks and tooling running the home lab: multimedia server, NAS, MCP servers, shared infra other repos attach to.

**[llm-gateway](https://github.com/preston-bernstein/llm-gateway)** — Self-hosted LiteLLM proxy as a hardened systemd service. One gateway for Anthropic, Gemini, and local Ollama.

**[fashion-monitor](https://github.com/preston-bernstein/fashion-monitor)** — Resale monitoring: scrapes listings, scores them with an LLM, alerts over Telegram.

**[Estate sale scanner](https://github.com/preston-bernstein/estate-scraper)** — Scrapes listings, runs Ollama vision to score images for valuable items, surfaces results in a dashboard. Making the garage sale circuit slightly less manual.

**[agent-orchestrator](https://github.com/preston-bernstein/agent-orchestrator)** — Local planning + execution harness for agent workflows. Feed it a spec, it plans, optionally gates on human approval, then executes. Inngest-compatible for event-driven runs.

**[proton-email-mcp](https://github.com/preston-bernstein/proton-email-mcp)** — MCP server for Proton Mail via Bridge (IMAP/SMTP). Works in Claude Code (stdio) and LibreChat (streamable-http).

**Algo trading research** *(private)* — Agentic strategy development with anti-overfit validation gates (deflated Sharpe, PBO, purged CV, Monte Carlo).
